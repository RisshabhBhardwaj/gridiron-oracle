### Scope of the forward producer (found 2026-11-14, after the coordinator approved wiring it)

Moving the guards is the small part. In `artifact_backed` mode, `PipelineRunner` (`ml/train.py`, around lines 824-880) loads fitted base models only from a reachable MLflow server ("latest finished run" per experiment), and it refuses to run otherwise. Three things are missing:

- The box runs no MLflow server.
- The release pins no fitted base models, only OOF stacks, ridge coefficients, attributions and the selection file.
- The 39 files in `ml/onnx/` date from 2026-08-21, are unpinned, cover only some cells and learners, and predate this release. Pairing them with this release's ridge coefficients would mix two releases.

Wiring it correctly means fitting final base models for every learner that fed each cell's ridge stack (training data up to `LAST_COMPLETE_SEASON`), pinning them by SHA-256 in the release manifest, loading the pinned files in `artifact_backed` mode instead of "latest MLflow run", then moving the guards and wiring the step into the refresh. A re-freeze follows. That is a design that is hard to undo (manifest schema, decision 0002), so it gets an architect review before anyone builds it.
