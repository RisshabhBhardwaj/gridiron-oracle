# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security-sensitive reports.

Email **bhardw30@purdue.edu** with:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept if available
- Any relevant logs, versions, or configuration details

You should receive an acknowledgment within a few business days. Please give a reasonable window for assessment and remediation before any public disclosure.
