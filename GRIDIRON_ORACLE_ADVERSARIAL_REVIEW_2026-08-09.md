## Executive verdict

**DO NOT SHIP this tree for draft use.**

The headline edge is not production-causal. The default feature set contains `snap_pct_off`, which is populated from the target game's postgame `offense_pct`. In the local database, 125,425 non-null feature values exactly equal the same-game `game_logs.offense_pct`; the feature's correlation with target PPR is 0.637. The post-release OOF, stack, evaluation, materialization, and draft artifacts all rely on that pre-existing feature contract. Expanding-window season folds do not cure within-game leakage.

The draft board then sums target-season weekly OOF rows—including postseason rows—to manufacture a “draft” rank. This conditions ranks on who actually appeared, how many games they played, their prior in-season results, and the leaked target-game snap feature. It does not directly sum `y_true`, but it is not a preseason prediction and does not satisfy the locked no-season-actuals intent.

Four more release blockers remain: Ridge failures are swallowed by the pipeline and silently replaced with Kalman/zero outputs; callable trainers regenerate forbidden XGB/TFT stacks; the public pre-push gate can publish a blocked file hidden in an ancestor of a new branch; and OOF discovery is demonstrably re-poisonable by touching a stale file.

There is real work worth preserving. Current dated stack CSVs and coefficient files are LGBM+CatBoost only, all 19 checked stack SHA sidecars match, current artifacts contain no 2026 folds, the local DB has 48,058 rows matching the ten materialized cells, the strict common-cohort score counts remain 20/20, 25/25, 5/5, and 24/25, the frontend builds, and the public Git tree appears sanitized. Those are necessary facts, not sufficient grounds to ship.
